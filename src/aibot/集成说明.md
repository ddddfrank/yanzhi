## 快速集成

### 方法一：在主界面中直接引入

在主界面的HTML文件（如 `src/main/main.html`）的 `</body>` 标签前添加：

```html
<!-- 引入AI助手 -->
<iframe id="aibot-frame" src="aibot/aibot.html"
        style="position: fixed; top: 0; left: 0; width: 100%; height: 100%;
               border: none; pointer-events: none; z-index: 9999;">
</iframe>

<script>
    // 确保iframe允许交互
    const aibotFrame = document.getElementById('aibot-frame');
    aibotFrame.style.pointerEvents = 'none';

    // 监听AI助手需要交互的事件
    window.addEventListener('message', (event) => {
        if (event.data.type === 'aibot:needsInteraction') {
            aibotFrame.style.pointerEvents = 'auto';
        }
        if (event.data.type === 'aibot:finishedInteraction') {
            aibotFrame.style.pointerEvents = 'none';
        }
    });
</script>
```

### 方法二：使用Electron BrowserWindow（推荐）

修改 `src/index.js`，在 `app.whenReady()` 中添加AI助手窗口：

```javascript
// 创建AI助手窗口
function createAIBotWindow() {
    const aibotWindow = new BrowserWindow({
        width: 400,
        height: 600,
        x: -1000, // 初始隐藏
        y: -1000,
        show: false,
        frame: false,
        transparent: true,
        alwaysOnTop: true,
        skipTaskbar: true,
        resizable: false,
        webPreferences: {
            preload: path.join(__dirname, 'aibot/aibot-preload.js'),
            nodeIntegration: false,
            contextIsolation: true,
        },
    });

    aibotWindow.loadFile(path.join(__dirname, 'aibot/aibot.html'));

    return aibotWindow;
}

// 在app.whenReady()中调用
app.whenReady().then(() => {
    // ... 现有代码 ...

    // 创建AI助手窗口
    const aibotWindow = createAIBotWindow();

    // 暴露给全局使用
    global.aibotWindow = aibotWindow;
});
```

### 方法三：通过主进程加载（当前推荐）

在 `src/index.js` 的主窗口加载完成后，注入AI助手：

```javascript
// 修改createWindow函数
const createWindow = () => {
    // ... 现有代码 ...

    mainWindow = new BrowserWindow({
        // ... 现有配置 ...
        webPreferences: {
            preload: path.join(__dirname, 'preload.js'),
            nodeIntegration: false,
            contextIsolation: true,
        },
    });

    // ... 现有代码 ...

    // 加载主页面
    mainWindow.loadFile(startupPage);

    // 页面加载完成后注入AI助手
    mainWindow.webContents.on('did-finish-load', () => {
        mainWindow.webContents.executeJavaScript(`
            // 动态创建AI助手的浮动窗口
            const link = document.createElement('link');
            link.rel = 'stylesheet';
            link.href = 'aibot/aibot.css';
            document.head.appendChild(link);

            const script = document.createElement('script');
            script.src = 'aibot/aibot.js';
            document.body.appendChild(script);

            // 创建AI助手DOM
            fetch('aibot/aibot.html')
                .then(response => response.text())
                .then(html => {
                    const parser = new DOMParser();
                    const doc = parser.parseFromString(html, 'text/html');
                    const trigger = doc.getElementById('aibot-trigger');
                    const window = doc.getElementById('aibot-window');

                    document.body.appendChild(trigger);
                    document.body.appendChild(window);

                    // 触发DOMContentLoaded事件以初始化脚本
                    document.dispatchEvent(new Event('DOMContentLoaded'));
                });
        `);
    });
};
```

## 功能说明

### 核心功能

1. **悬浮助手按钮**
   - 位于页面右下角
   - 点击打开AI助手窗口
   - 渐入渐出动画效果

2. **智能问答**
   - 基于用户使用文档的知识库
   - 支持常见问题快速回答
   - 集成AI API处理复杂问题

3. **快捷问题**
   - 预设常见问题按钮
   - 一键获取答案
   - 覆盖主要功能场景

4. **对话历史**
   - 记录最近10条对话
   - 支持上下文理解
   - 提供更精准的回答

### 支持的问题类型

- ✅ 安装配置问题
- ✅ 功能使用方法
- ✅ 快捷键操作
- ✅ 文献管理
- ✅ AI功能使用
- ✅ 常见问题解决
- ✅ 数据备份迁移

### 知识库管理

知识库位于 `aibot.js` 的 `buildKnowledgeBase()` 方法中：

```javascript
buildKnowledgeBase() {
    return {
        '分类名称': {
            keywords: ['关键词1', '关键词2', ...],
            response: '回答内容...'
        },
        // ... 更多分类
    };
}
```

**添加新的问答：**

1. 在 `keywords` 数组中添加相关问题关键词
2. 在 `response` 中编写详细的回答
3. 支持Markdown格式的富文本
4. 使用 `\`` 表示代码块
5. 使用 `**` 表示粗体

## 自定义配置

### 修改悬浮按钮位置

在 `aibot.css` 中修改 `.aibot-trigger` 样式：

```css
.aibot-trigger {
    bottom: 30px;      /* 距离底部 */
    right: 30px;       /* 距离右侧 */
    /* 也可以改为 left 或 top */
}
```

### 修改颜色主题

在 `aibot.css` 中修改渐变色：

```css
/* 主色调 */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* 修改为其他颜色 */
background: linear-gradient(135deg, #your-color-1 0%, #your-color-2 100%);
```

在 `aibot.html` 中修改按钮：

```html
<button class="aibot-quick-btn" data-question="你的问题">按钮文本</button>
```

## 故障排除

### AI助手不显示

1. 检查文件路径是否正确
2. 查看浏览器控制台错误
3. 确认CSS和JS文件已加载

### AI回答不准确

1. 检查知识库关键词是否完整
2. 更新 `buildKnowledgeBase()` 方法
3. 验证API配置是否正确

### 悬浮按钮不响应

1. 检查z-index层级
2. 确认没有其他元素遮挡
3. 查看事件监听器是否正确绑定
